# NeurIPS-2025-Weak-Lensing-Uncertainty-Challenge

In this project we aimed to address a problem from the Weak Lensing Uncertainty Challenge organized by the FAIR Universe. The challenge under consideration is to predict cosmological parameters from weak lensing maps. In this project, we not only proposed an improved baseline, but also tried compare our solution with those provided by a state-of-the-art multi-agent AI system designed as a scientific research assistant.

## Repository structure

### `Denario/`
Contains all artifacts generated by the **Denario multi-agent AI system**.  
This folder includes AI-generated research logs, exploratory analyses, architectural proposals, and intermediate experimental reasoning produced autonomously by the system.  
All content in this directory is fully AI-generated and is provided for transparency, auditability, and analysis of autonomous scientific workflows.


### `Pipelines/`
Contains end-to-end machine learning pipelines used throughout the project.  
This includes data loading, preprocessing, model definition, training loops, validation logic, and evaluation utilities, enabling reproducible experimentation across different model variants.

### `Pretrained_pth_files/`
Stores pretrained model weights (`.pth` files) corresponding to the proposed CNN architectures, baselines, and intermediate variants.  
These files allow direct reproduction of inference results without retraining models from scratch.

### `Project_Presentation/`
Contains presentation materials related to the project, such as slides used for project defenses, internal reviews, or conference-style presentations summarizing the methodology and results.

### `Results/`
Contains experimental results and visualizations, including performance plots, score comparisons, and figures used in the paper and README (e.g., `scores.png`).

## Main notebook

### `main.ipynb`
The `main.ipynb` notebook serves as the **primary experimental entry point** for the project.  
It orchestrates the full workflow, including:
- loading and preprocessing the weak-lensing dataset,
- initializing and configuring model architectures,
- training models under different configurations,
- evaluating performance on the held-out test set using the official scoring metric,
- comparing baseline methods, Denario-generated solutions, and the proposed CNN variants.

This notebook is intended for **experimentation, result reproduction, and comparative analysis**, and reflects the final experimental setup used to generate the reported results.
